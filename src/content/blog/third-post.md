This was a project that was created with the intention of automating a clients prices database based on flyers that they would submit to the application. The application would take in a sales flyer and then it will send it to an OCR application which will read the raw text and then map it into the applications database. From there the client can look at the prices in the applications database and modify them to fine tune the llm or update the prices in the companies price database.
